# 中考前六周：同班抉择沙盘

这是一个面向初中生的课堂决策游戏。六个小组分别支持六位同班学生，在中考前六周依次处理家庭安排、学习冲突、模拟考、同伴合作、疲劳调整和考场准备。

游戏不比较谁走得更快。学生需要从两个具体方案中选择一个，说明理由，并承担它对勇气、知识、时间和同伴关系造成的影响。

## 快速启动

项目不需要安装依赖。进入仓库目录后运行：

```bash
python3 -m http.server 8766 --directory game
```

然后在浏览器打开：

```text
http://127.0.0.1:8766/
```

Windows 也可以使用：

```powershell
py -m http.server 8766 --directory game
```

如果 `8766` 端口已被占用，把命令和网址中的端口改为 `8767` 等其他数字。

## 课堂准备

- 建议对象：初中生
- 建议分组：6组，每组支持1位学生
- 建议设备：教师电脑、投影或大屏
- 建议时长：45分钟；讨论较充分时可安排2课时
- 建议分工：朗读事件、分析资源、记录理由、代表选择、观察搭档影响

六位人物都是虚构角色。课堂讨论应围绕游戏情境，不要求学生公开自己的家庭、成绩或个人经历。

## 开始游戏

1. 点击“查看人物档案”，依次阅读六位学生的家庭、性格、优点、短板和目标。
2. 六份档案全部读完后，点击“开始第一周”。
3. 每周先阅读本周故事，再由六位学生按顺序各抽1张事件牌。
4. 阅读事件和两个行动方案，小组选择一个方案，并填写一句具体理由。
5. 六人都完成后查看“班级回声”，再进入下一周。
6. 第六周结束后查看六位学生的成长画像，并完成成长策略单。

每周固定有6张牌，机遇、挑战、抉择各2张；个人、搭档、全班事件分别为3、2、1张。六周共处理36张牌，不会提前结束。

## 三种事件

| 类型 | 处理方式 |
| --- | --- |
| 个人卡 | 根据当前学生的家庭、性格和本周处境作出选择 |
| 搭档卡 | 同时影响固定搭档中的两个人，并可能改变默契 |
| 全班卡 | 全班讨论或投票，记录多数选择及对另一种意见的处理 |

每张牌提供两个可执行方案。没有统一正确答案，但理由必须说明具体行动、现实代价和仍需本人承担的部分。

## 家庭与老师的矛盾线

六周中会出现统一冲刺表、家庭责任、公开排名、班级答疑、手机管理和志愿方向等矛盾。家长和老师不是反派，他们各自承担责任，但掌握的信息、关注的风险和学生的现实条件可能不同。

处理相关卡牌后，学生侧栏会保留两项状态：

- `待沟通`：方案暂时执行，但规则、边界或检验结果还没有谈妥；
- `已协商`：学生说明了限制和承担，成人也保留了自己的合理关切，形成了可执行安排。

沟通状态会进入行动记录和最终结局。它不作为排名分数，也不会淘汰人物。课堂只讨论虚构人物，不要求学生讲述自己的家庭、成绩或真实矛盾。

## 资源规则

| 资源 | 在游戏中的含义 |
| --- | --- |
| 勇气 | 面对问题、开口沟通、接受不确定结果的能力 |
| 知识 | 通过练习、订正、提问和整理真正留下的方法 |
| 时间 | 可以用于学习、休息、家庭和同伴任务的可支配安排 |
| 能量币 | 每周最多使用1枚，抵消当前卡牌造成的1点资源损失 |

勇气、知识、时间的上限为12，能量币上限为6，所有资源最低为0。

任一核心资源降到0时，人物不会被淘汰，也不会跳过行动。下一次操作前需要完成调整任务：

1. 写明删掉或缩减的任务；
2. 指定一个求助对象；
3. 写出具体执行时间。

完成后，对应资源恢复到1点。

## 搭档与支援

固定搭档为：

- 林晓晨 × 吴辰安：同桌，计划与弹性
- 周雨桐 × 赵思齐：物理学习搭档，开口与融入
- 陈子航 × 何嘉宁：班级任务搭档，行动与节奏

默契初始为1，范围为0至3：

- 默契达到2时，这组搭档解锁一次支援。
- 受损学生本人决定是否接受支援。
- 接受后，受损学生少损失1点；提供支援的搭档同时损失1点同类资源。
- 支援者结算后不足1点该资源时，支援选项不会出现。
- 默契达到3时，两人在第六周各获得1枚能量币，并生成共同成长结局。

## 顶部按钮

| 按钮 | 功能 |
| --- | --- |
| `♪` | 开启或关闭声音 |
| `动 / 静` | 开启或减少翻牌等动态效果 |
| `▤` | 查看六周故事目录 |
| `▣` | 打开3个手动存档位 |
| `↶` | 撤回本局上一步操作 |
| `?` | 查看游戏规则 |
| `↻` | 重新开始六周故事 |

撤回按整局操作记录生效，可以一直退回人物准备阶段。撤回抽卡后，同一张牌会回到牌堆顶部，不能通过反复撤回来换牌。

重新开始会清除当前自动进度，但不会删除3个手动存档位。

## 存档说明

- 当前进度会自动保存在本浏览器中。
- 手动存档有3个位置，会保存牌序、当前学生、资源、默契和行动记录。
- 刷新页面后可以继续当前进度。
- 存档只存在当前浏览器和当前设备中；清除网站数据可能导致存档丢失。
- 旧地图版本的存档会保留，但不能直接载入当前抽卡版本。

## 45分钟课堂流程

| 时间 | 教师与学生操作 |
| --- | --- |
| 0–5分钟 | 分组并阅读六份人物档案 |
| 5–8分钟 | 说明资源、三种卡牌和搭档支援，演示一次选择 |
| 8–38分钟 | 完成六周游戏；每周约5分钟，每次选择控制在30–40秒 |
| 38–43分钟 | 填写成长策略单，各组选出一次关键选择或调整 |
| 43–45分钟 | 总结选择、代价、求助、调整与韧性的关系 |

若学生需要充分讨论，建议把前三周和后三周拆成两课时，并使用手动存档衔接。

## 结课时看什么

游戏根据人物最终资源生成成长画像：

- 勇气最高：探索者
- 知识最高：学习者
- 时间最高：规划者
- 三项资源差距不超过2点：平衡成长者
- 两项资源并列最高且不满足平衡条件：同时显示两个画像

画像不是排名。结课讨论应优先关注：选择理由是否清楚、是否看见了代价、受挫后是否提出了可以执行的调整。

## 常见问题

### 页面刷新后还是旧内容

先执行一次强制刷新。若仍未更新，关闭同一地址的旧标签页后重新打开。

### 页面打不开

确认终端中的本地服务器仍在运行，并检查网址端口是否与启动命令一致。

### 误操作后如何恢复

点击顶部 `↶` 撤回。若已经重新开始，可从 `▣` 中读取之前的手动存档。

### 一节课做不完怎么办

在第三周“班级回声”结束后保存，下一课时读取该存档继续。不要为了赶进度跳过理由记录，否则资源变化会失去教学意义。

## 项目结构

```text
game/
├── index.html       # 页面结构
├── styles.css       # 视觉样式与响应式布局
├── app.js           # 六位人物档案等基础内容
├── card-game.js     # 六周牌组、规则、存档与撤回逻辑
└── assets/          # 页面图标和插图素材
```

游戏采用原生 HTML、CSS 和 JavaScript，可以直接部署到任意静态网站服务。
